Inputs
  - event — required, type EventDetailResponse
  - backLink — string[], defaults to ['/dashboard/events'] (add-edit-ticket-type passes ['/dashboard/events', ev.externalId])

  Template
  - Hero div with banner image (conditional), dark overlay, back button, status badge, category, title
  - <ng-content select="[heroActions]"> slot inside a <div class="hero-actions"> for optional action buttons (event-details passes Edit / Go Live; add-edit-ticket-type passes
  nothing)
  - Info-strip below the hero: venue (venueName, venueCity, venueCountry), date (EEE, d MMM yyyy), time range (HH:mm — HH:mm), public/private visibility — all pipe-separated
  with dividers

  Imports
  - DatePipe, TitleCasePipe, RouterLink, MatButtonModule, MatIconModule

  CSS
  - All hero styles: .hero, .hero--no-banner, .hero-img, .hero-overlay, .hero-back (+ hover), .hero-content, .hero-meta, .hero-category, .hero-bottom, .hero-title,
  .hero-actions
  - Status badge styles: .status-badge, .status-draft, .status-published, .status-cancelled
  - Info-strip styles: .info-strip, .info-strip-item, .info-strip-item mat-icon, .info-strip-divider
  - Responsive (max-width: 768px): hero aspect ratio, hero-bottom column layout, hero-actions full width, info-strip-divider hidden

  Usage in event-details
  <app-event-hero [event]="ev" [backLink]="['/dashboard/events']">
    <ng-container heroActions>
      <!-- Edit and Go Live buttons -->
    </ng-container>
  </app-event-hero>

  Usage in add-edit-ticket-type
  <app-event-hero [event]="ev" [backLink]="['/dashboard/events', ev.externalId]" />
